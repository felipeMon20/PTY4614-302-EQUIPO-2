# Base de datos

El sistema no usa una base de datos relacional: la fuente de datos son archivos Excel y CSV compartidos (ver `../Aplicación/README.md` y la documentación en `../../Evidencias de documentación/docs`).

Esta carpeta contiene los **archivos de referencia con datos ficticios** (mismas columnas y formato que los reales). La aplicación trabaja con su propia copia en `../Aplicación/duoc/archivos de referencia`, a través de `preparar_demo.py`.

Los diagramas del modelo de datos están en `../../Evidencias de documentación/diagramas` (`modelo_datos_1_origen.drawio` y `modelo_datos_2_integracion.drawio`).
